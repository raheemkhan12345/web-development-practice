#  Getting Started

Clone the repository

```bash
git clone https://github.com/raheemkhan12345/frontend-practice-projects.git
```

Open the project

```bash
cd frontend-practice-projects
```

For HTML Projects

```bash
Open index.html
```

For React Projects

```bash
npm install

npm run dev
```
